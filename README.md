# Python - Aulas e Exercícios (1TIAPR 2026)

Repositório com os exercícios que resolvi nas aulas de Python da turma **1TIAPR 2026**, no curso de Inteligência Artificial da FIAP. Cada pasta `aula_N` reúne os exercícios daquela aula, e `checkpoint_1` traz a resolução do primeiro checkpoint.

## Conteúdo

| Pasta | Assuntos praticados |
|---|---|
| `aula_1` | Variáveis, `input`, operações matemáticas e formatação de saída (área do círculo, conversão de temperatura, cálculo de compras) |
| `aula_2` | Condicionais `if / elif / else` (número positivo ou negativo, ano bissexto, idade para votar) |
| `aula_3` | Listas, `sum`, `join` e laço `for` com `range` |
| `aula_4` | Laços `for` e `while` (somatório, fatorial, tabuada, jogo de adivinhar o número com `random`) |
| `aula_5` | Menus e estruturas `match / case` (dias da semana, estações do ano, faixas de idade e de nota) |
| `aula_6` | Matrizes (listas de listas) |
| `aula_7` | Funções (definição, parâmetros e retorno) |
| `aula_8` | Leitura e escrita de arquivos com `with open` |
| `aula_9` | Manipulação de arquivos: contar palavras, concatenar arquivos, buscar palavra e ordenar nomes |
| `aula_10` | Orientação a objetos: classe `Pessoa` com atributos e métodos |
| `checkpoint_1` | Checkpoint 1: condicionais, listas, `for`, `while`, validação de entrada com `try / except` e matrizes |

## Como executar

Requer **Python 3.12 ou superior** (alguns exercícios usam `match / case` e f-strings com aspas aninhadas).

```bash
cd aula_4
python ex07.py
```

Os exercícios das aulas 8 e 9 leem e escrevem os arquivos `.txt` que estão na raiz do repositório, então execute-os a partir dessa pasta:

```bash
python aula_9/ex01.py
```
